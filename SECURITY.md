# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within NexaVoice, please do not disclose it publicly or file a public GitHub issue. 

Please send security reports to `security@nexavoice.internal` with:
- Description of vulnerability and impact
- Steps to reproduce or proof-of-concept
- Affected components or endpoints

All security reports will be acknowledged within 24 hours with coordinated vulnerability management.
